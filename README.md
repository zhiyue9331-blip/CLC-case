# 全域土地综合整治项目组 · 成果发布站

项目首页：https://shuwgc.github.io/CLC-case/

本仓库提供成果发布网页，安装包在公开上传并核验后通过GitHub Releases分发；当前未上传的附件明确标为待上传。研究说明、软件快照、过去版本与开发日志分别呈现。论文成果按实际进展收录。

静态页面为index.html、versions.html、log.html。releases.json记录公开安装包地址、主要改动及历史快照；同号构建保留独立安装包。素材与字体说明见CREDITS.md。

本地审阅与合并前检查见[DEPLOY.md](DEPLOY.md)。
